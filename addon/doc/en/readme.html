Key Presser

Key Presser repeatedly sends a key, a sequence of keys, a piece of text or a mouse click at an interval that you choose. It uses low level scan code injection, so it reaches games and engines that read raw input, including SDL, DirectInput and Unity titles, as well as ordinary Windows programs, browsers and Python applications.

Warning

This add-on was written for experiments only. I don't encourage cheating with this.

The same warning appears in a small window the first time the add-on runs. Once you close it with OK or Escape, it never comes back by itself. It can be shown again from the settings, or with a command you can assign a gesture to.

The window does not block NVDA while it is open, so you can keep using the NVDA menu, the settings and NVDA Remote even if you have not closed it yet.

The unassigned commands can be given a gesture in NVDA menu, Preferences, Input gestures, under the Key Presser category. The interval commands work while the presser is running, so you can speed it up or slow it down live.

Settings

The settings are reached with NVDA+y, or from NVDA menu, Preferences, Settings, Key Presser. Everything is stored per profile and is written to disk when you press OK or Apply.

Profiles

Each profile is a complete, independently saved set of options. Create as many as you like with New, Duplicate, Rename and Delete, then move between them with NVDA+alt+z without opening the settings at all.

What to send

  • Mode: keys and text, or a mouse button. Only the controls that belong to the chosen mode are shown, so there is nothing irrelevant to tab past.
  • Sequences: a profile holds as many sequences as you like, each with a name and a tick box. Only the ticked ones run, one after another, in the order they appear in the list; the unticked ones stay exactly as they are for later. Space toggles the tick, the arrow keys move between sequences, and New, Duplicate, Rename and Delete manage the list. This is how you keep, say, an Attack sequence and a Chat sequence side by side and turn one off without losing it.
  • Steps of the selected sequence: the steps played in order whenever that sequence runs. Keys and pieces of text live in the same list, so a step can be a key, a whole sentence, or a pause, in whatever order you like. Nothing has to be typed by hand; the list is built with the buttons underneath it.
    • To press Y and then Enter, add Y, then add Enter. To type a name and then confirm it, add a text step with the name, then add Enter. The gap between two steps is the pause between steps, under Timing; the interval is the wait before the whole sequence starts again.
    • Add key opens a chooser. Pick a category, pick a key from the list, tick any of Control, Shift, Alt and Windows, and press OK. The new step is inserted after the one that is selected. The categories are letters, digits, function keys, navigation, editing, numpad, modifier keys, locks and system, media, punctuation, and raw code, which together cover 124 keys.
    • Add text opens a multi line box. The text is sent as Unicode characters, so it works whatever the keyboard layout is, and every line break in the box becomes a real Enter press. Commas, backslashes and spaces at the end of the text are handled for you.
    • Add random makes one step that has several options, one of which is picked at random every single time the step runs. Choose whether the options are plain texts or keys, then write one option per line. Use it so a repeated message is never quite the same twice, or so a key varies from cycle to cycle. Two options are the minimum.
    • Add pause inserts a wait of as many milliseconds as you like between two steps.
    • Edit reopens the right box for the selected step, whichever kind it is. Remove, Move up and Move down do what they say.
    • Raw code is the last category in the chooser. It takes vk:0x41 for a virtual key code or sc:0x1E for a scan code, for games that expect an exact hardware code.
    • Type the sequence is there if you would rather write the whole thing out at once, in the comma separated form, for example ctrl+a, w, wait:500, f5. A text step is written as text:hello, and inside it a comma is written \,, a line break \n, a backslash \\, and a space at the very end of the text \s. Spaces around the plus sign of a combination are allowed, so ctrl + a means the same as ctrl+a. The sequence is checked before it is accepted, and the result goes straight back into the list.
  • Mouse button: left, right, middle, the fourth and fifth buttons, or the wheel up and down.
  • Sending method: scan codes are the default and are what games and SDL applications expect. Switch to virtual key codes if a standard window ignores the key.

Timing

  • Interval: milliseconds between actions, from 1 to one hour. The schedule is absolute, so the add-on does not drift over long runs, and Windows timers are switched to their highest resolution while it is running.
  • Random variation: adds or subtracts up to this many milliseconds at random on every cycle, so the rhythm is not perfectly mechanical.
  • Hold: how long each key or button stays down. Some games ignore presses that are shorter than one frame, so raise this to 30 or 50 milliseconds if a game does not react.
  • Pause between steps: the gap between one step of a sequence and the next. Raise it when a key needs time to take effect before the next step arrives, for example a key that opens a chat box before the text is typed.
  • Milliseconds between the characters of a text step: the typing speed, kept separate from the pause between steps so that a long pause between steps does not also slow the typing to a crawl.
  • Delay before the first action, with an optional spoken countdown, so you have time to switch to the target window after starting.

Limits and feedback

  • Stop after this many actions and stop after this many seconds, either of which ends the run on its own. Zero means unlimited.
  • Only run while these programs are in the foreground: a list of executable names separated by semicolons, for example game.exe; player.exe. The presser pauses whenever another window takes focus and resumes when the target returns. The name can also be captured from the foreground window with a gesture.
  • Announce the action count every so many actions.
  • Beeps when starting, pausing, resuming and stopping.
  • Spoken status messages.
  • Silence typed character and command key announcements while running, so NVDA does not read every injected key back to you. The previous settings are restored when the presser stops. This option changes NVDA's own keyboard settings while the presser runs, so if NVDA is closed by force during a run, they can stay off and you will have to turn them on again in NVDA's keyboard settings.

Notes

  • Input is injected at the system level, so it goes to whichever window has focus. Make sure the right window is in the foreground, or use the program restriction.
  • Applications that run elevated, as administrator, only accept injected input if NVDA is also running elevated.
  • NVDA+z always stops the presser at once, even in the middle of a long sequence or a long key hold, and any key that is still held down is released.
  • The add-on does nothing on secure screens, such as the Windows logon screen and User Account Control prompts.
